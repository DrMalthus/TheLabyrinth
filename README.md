# The Labyrinth

> A dark place few people are brave enough to enter, yet stay the night and find out it's secrets.

This mod contains a pre-built Labyrinth. Explore all of it's secrets and shape your own path to get out alive.

---

## Planned Features:

- Procedural Labyrinth generation
- Multiple types of Labyrinths
- better monster(s)
- RogueLite Mode - collect Tiles to change up your game
- Non-Scripted Labyrinth movements

---

## Usage Guide:

Spawn the Labyrinth with the following command:

```
/labyrinth:spawn
```
